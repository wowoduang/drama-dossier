# v3.4 剧情理解与多模态精彩剪辑质检

## A. 片源与采集
- [ ] 视频版本、集数、时长、帧率、音轨、字幕轨已记录。
- [ ] 字幕/ASR 时间轴与视频抽样校准。
- [ ] 镜头变化、音量峰值、低能量区间只作为定位线索。
- [ ] 均匀关键帧覆盖全片，不只抽取模型认为“精彩”的时间点。
- [ ] 关键动作、人物身份、说话人和反应镜头回看连续原片。

## B. 证据与剧情事实
- [ ] 每条关键结论有稳定 ID 和可回看证据。
- [ ] 事实、推断、假设、主题解读分开。
- [ ] 人物被提及没有误记为参与事件。
- [ ] 计划、命令、威胁、回忆、想象没有误写为当前现实事件。
- [ ] AI 视觉导入结果保持 `UNREVIEWED`，无批量自动通过。
- [ ] 人物未知时使用描述/`null`，不编造人物 ID。

## C. 场景、事件、关系和因果
- [ ] 场景边界不是只由字幕空档决定。
- [ ] 事件区分 Actor/Patient/Recipient/Target。
- [ ] 关系方向和时间范围明确。
- [ ] 时间先后没有直接冒充因果。
- [ ] 因果边包含依据、推理说明和必要反证。
- [ ] 角色当时认知没有被后续揭示覆盖。

## D. 多模态弧线候选
- [ ] `setup / peak / reaction / payoff` 每一段均回看连续原片。
- [ ] `payoff` 与锚点有同剧情线或直接因果关联，而非仅仅时间较晚。
- [ ] 缺少语义支持的段落保留在 `missing_roles`。
- [ ] 声音峰值不是自动当作情绪高潮。
- [ ] 镜头切换不是自动当作场景切换或动作转折。
- [ ] 关键帧没有被当作完整动作证据。

## E. 高光与剪辑序列
- [ ] 高光解释“为什么值得剪”，不只给总分。
- [ ] 七维评分与剧情相符；高分不等于事实等级更高。
- [ ] `context_required=high` 的片段没有在短成片中被断章取义。
- [ ] 高光起止点没有截断关键台词、动作或反应镜头。
- [ ] 默认按故事/播放时间顺序；打乱顺序有明确目的。
- [ ] 预览成片没有把回忆/想象/假设造成现实误导。
- [ ] 输出总时长符合预设或记录偏差原因。

## F. 审核与交付
- [ ] JSON 是剧情唯一事实源；剪辑项目只引用它，不反向修改事实。
- [ ] 关键对象无未解释的 `NEED_EVIDENCE / DISPUTED`。
- [ ] 修改保留审核历史。
- [ ] 已连续预览 edit-project。
- [ ] FFmpeg 渲染结果已抽查首尾、音画同步和片段顺序。

## v3.7 跨集故事弧追加检查

- [ ] setup / inciting incident / escalation / peak / reaction / payoff / resolution 是否都有真实事件支撑？缺失角色是否明确标记，而非编造？
- [ ] 每段事件 ID、证据 ID 是否属于正确集数，并且证据确实关联所选事件？
- [ ] 是否将时间相邻误当成因果？跨集因果边是否已人工核验？
- [ ] 计划/命令/威胁/愿望是否被误剪成行动已经执行？
- [ ] 角色与观众在每个关键节点分别知道什么？是否发生未来信息倒灌？
- [ ] 是否标明非线性剪辑理由和潜在剧透风险？
- [ ] 若原片档案被更新，相关跨集因果审核是否重新打开？
- [ ] `release_ready` 是否为 true；若不是，是否保留了警告并交由人工处理？
