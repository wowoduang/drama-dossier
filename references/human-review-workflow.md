# v3.4 人工审核交互规范

## 推荐模式：本地 Web 工作台 + ChatGPT 技能协作

ChatGPT 技能负责解释任务、分析候选和生成结构化数据；本地 Web 工作台负责原片定位、逐项核验、人工修订和导出。Python 负责结构校验与批处理。三者通过 JSON 交换，不通过 Markdown 文本替换同步。

## 审核步骤

1. 在工作台打开当前剪辑版本的单集 JSON。
2. 载入与 JSON `source_version` 完全一致的本地视频；版本不一致时不得复用时间码。
3. 从左侧选择证据、人物、出场、场景、事件、关系、因果边或伏笔。
4. 点击证据卡片或时间轴标记，跳转到原片时间码核对。
5. 修改对象字段并勾选直接支持该对象的证据。
6. 选择 `PASS / NEED_EVIDENCE / INCORRECT / DISPUTED`，填写审核理由。
7. 提交后产生一条追加式审核历史，包含旧值、新值、审核者、时间、理由和证据 ID。
8. 导出 JSON，运行 `dossier_v3.py validate`；严格交付前运行 `validate --strict`。

## 交互约定

- `PASS` 不提升事实等级；事实等级必须依据证据本身判断。
- `NEED_EVIDENCE` 不删除对象，待补证后重新审核。
- `INCORRECT` 保留原记录和错误原因，修订值进入新版本。
- `DISPUTED` 保留冲突证据与竞争性解释，不强行选择。
- 不确定人物槽位允许为空；不允许为了表格完整而猜测。
- 场景边界候选默认 `uncertain`；镜头切换不自动等于语义场景切换。

## 隐私与文件安全

审核页面是本地静态 HTML，不自动上传视频或档案。页面内修改只存在于浏览器内存，必须导出 JSON 才会保存。建议保留原始 JSON 只读副本，并按日期/剪辑版本另存审核后文件。仅在本机回环地址启动服务器，不要暴露公网。
